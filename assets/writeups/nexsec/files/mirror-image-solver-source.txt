 def hall(lo, hi):
   sieve = bytearray([1]) * (hi + 1)
   sieve[0:2] = b"\x00\x00"
   for i in range(2, int(hi ** 0.5) + 1):
      if sieve[i]:
          sieve[i * i::i] = bytearray(len(range(i * i, hi + 1, i)))
   return [p for p in range(lo, hi + 1) if sieve[p]]


 def pick(pool, count):
   pool = list(pool)
   return [pool.pop(randbelow(len(pool))) for _ in range(count)]

      xs[i], xs[j] = xs[j], xs[i]

The server picks:
    ●​ 112 random 16‑bit primes m₁ … m₁₁₂ (all in [2^15, 2^16))
    ●​ A secret s, uniformly random in [0, 2^1024) (1024‑bit integer)
For each prime mᵢ, it reveals:
    ●​ s mod mᵢ (the true residue)
    ●​ rᵢ (a random decoy in [0, mᵢ))
In random order, so we get a pair (aᵢ, bᵢ) with exactly one being s mod mᵢ. Finally, it derives key
= SHA256(s), encrypts the flag with AES‑GCM, and prints (nonce, ciphertext) as ward.

Why naive CRT fails​
If we knew which residue in each pair was correct, we'd just CRT them:
    ●​ Product of all 112 primes: ∏ mᵢ ≈ 2^(15.5 × 112) ≈ 2^1736
    ●​ Since s < 2^1024 < 2^1736, CRT gives s uniquely.
But we have two choices per mirror, so there are 2^112 possible residue combinations. Only
one gives a CRT result < 2^1024; every other choice produces a uniform value in [0, 2^1736),
which is < 2^1024 with probability 2^(-712). So the correct combination is unique, but we can't
enumerate 2^112.

Why this is a lattice problem
For each mirror, define:
   ●​ aᵢ = first shadow, bᵢ = second shadow
   ●​ Δᵢ = (bᵢ − aᵢ) mod mᵢ
   ●​ δᵢ ∈ {0, 1} — which shadow is real
 s ≡ aᵢ + δᵢ · Δᵢ (mod mᵢ)
Multiply both sides by Δᵢ⁻¹ mod mᵢ:
 s · invᵢ − aᵢ · invᵢ ≡ δᵢ (mod mᵢ)
where invᵢ = Δᵢ⁻¹ mod mᵢ. Rearranged as an integer equation:
 s · invᵢ − kᵢ · mᵢ − baseᵢ = δᵢ      (*)
with baseᵢ = (aᵢ · invᵢ) mod mᵢ, kᵢ ∈ ℤ, and δᵢ ∈ {0, 1}.
This is exactly the Hidden Number Problem (HNP): we know s is small (1024 bits) and the
"error" δᵢ is tiny (0 or 1) for 112 equations. Lattice reduction (LLL) recovers s.

Constructing the Lattice
From (*), the vector we want to be short is:
 (W·δ₀, W·δ₁, …, W·δ_{n−1}, s, W)
The W = 2^1024 factor on the δ coordinates balances magnitudes: the δᵢ are 0/1 (tiny), while s ~
2^1024. Without scaling, LLL would ignore the tiny δ coordinates. After scaling, both W·δᵢ and s
are the same order.
The last coordinate W is the embedding/marker column only the base row touches it, which lets
the lattice contain a vector of the exact shape above.

Basis (dimension n + 2)
         Column range                          Meaning                        Weight

 0 … n−1                          residue / δ coordinates         W

 n                                carries s                       1

 n+1                              embedding marker                W
Rows:
 row i (i < n): W·mᵢ in col i
 row n        : W·invᵢ in cols 0..n−1, 1 in col n ← carries s
 row n+1      : W·baseᵢ in cols 0..n−1, W in col n+1
Key points:
   ●​ The invᵢ row is what makes s appear — without it, column n is identically zero and s is
       invisible to the lattice.
   ●​ The mᵢ diagonal rows "kill" the kᵢ.
   ●​ The baseᵢ row plus its W in the embedding column provides the short target vector.

The planted short vector
 s·(inv row) − Σ kᵢ·(row i) − 1·(base row)
  = ( W·δ₀, …, W·δ_{n−1}, s, −W )
Last entry is −W; column n is s. So in the reduced basis we find the row with last entry ±W, then
read s from column n, flipping the sign to match.

# ---------------- HNP lattice ----------------
# s*inv_i - k_i*m_i - base_i = delta_i, delta_i in {0,1}
# inv_i = (b_i - a_i)^{-1} mod m_i
# base_i = a_i * inv_i mod m_i
#
# dim = n+2:
# cols 0..n-1 : delta coords, weighted by W
# col n         : s coordinate (only the inv row puts '1' here)
# col n+1 : embedding col, only the base row (= W)
#
# rows:
# i<n : W*m_i in col i
# n : W*inv_i in cols 0..n-1, 1 in col n               <-- carries s
# n+1 : W*base_i in cols 0..n-1, W in col n+1
#
# short vector = s*(inv row) - sum k_i*(row i) - 1*(base row)
#            = (W*delta_i, s, -W)       -> last entry -W, col n = s
# (sign convention: the -1*(base row) gives last = -W; col n = s directly)
# But depending on how LLL orients the vector we may see (…, -s, W), hence
# the sign pairing below.

W = 2**1024
ms = [data[i][0] for i in range(len(data))]
opts = [data[i][1] for i in range(len(data))]
a_i = [o[0] for o in opts]
b_i = [o[1] for o in opts]
diff = [(b_i[i] - a_i[i]) % ms[i] for i in range(len(ms))]
inv = [inverse_mod(diff[i], ms[i]) for i in range(len(ms))]
base = [ (a_i[i] * inv[i]) % ms[i] for i in range(len(ms)) ]

n = len(ms)
dim = n + 2
print(f"[*] lattice dim {dim}")

rows = []
for i in range(n):
   r = [0]*dim; r[i] = W * ms[i]; rows.append(r)

r = [0]*dim
for i in range(n):
   r[i] = W * inv[i]
r[n] = 1                # carries s into column n
rows.append(r)

r = [0]*dim
for i in range(n):
   r[i] = W * base[i]
r[n+1] = W
rows.append(r)

def extract(reduced):
