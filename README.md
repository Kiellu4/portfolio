# Muhammad Ezekiel Mukhriz — Portfolio

Static portfolio site for me, built with HTML, CSS, and JavaScript.

## Deployment

The repository is designed for GitHub Pages at `https://kiellu4.github.io/portfolio/`. Push only after reviewing the local commits, then enable **Settings → Pages → Deploy from a branch → main / root**.

## Privacy

Only reviewed, metadata-stripped assets belong in `assets/`. This repository must not contain internal company material, personal addresses, phone numbers, references, credentials, certificate IDs, QR codes, API keys, or tokens.
